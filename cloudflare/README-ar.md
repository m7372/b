# تثبيت Worker لموقع لَمعة

هذا الـWorker يوفّر واجهة API محدودة لـXtream ومصادر بث موقّعة ومشفّرة، ويمرّر HLS وTS والملفات الأخرى دون وضع اسم المستخدم أو كلمة المرور في المتصفح. ضع `worker.js` في مشروع Cloudflare Worker، ثم اضبط القيم التالية من لوحة Cloudflare. لا تضع أسرار Xtream داخل GitHub.

## الإعدادات

أضف المتغيرات/الأسرار التالية في **Settings → Variables and Secrets**:

- `UPSTREAM_ORIGIN` متغير: أصل خادم Xtream مثل `http://HOST:2095` (الأصل فقط، بلا مسار). استخدام HTTP يعني أن الاتصال بين Cloudflare ومصدر Xtream غير مشفّر؛ اطلب HTTPS رسميًا إن كان متاحًا.
- `XTREAM_USERNAME` سر، و`XTREAM_PASSWORD` سر: بيانات Xtream الجديدة. غيّر كلمة المرور التي سبق أن شاركتها قبل استعمال الحساب.
- `APP_ACCESS_PASSWORD` سر: كلمة المرور التي يدخلها المستخدم في الموقع للسماح بالاتصال بالـWorker. ليست كلمة مرور Xtream.
- `SESSION_SIGNING_SECRET` سر عشوائي طويل مستقل لتوقيع جلسة API، و`MEDIA_TICKET_SECRET` سر عشوائي طويل آخر لتشفير روابط التشغيل المؤقتة. لا تستخدم قيمة واحدة لهما.
- `ALLOWED_ORIGIN` متغير: أصل الموقع الدقيق، مثل `https://username.github.io`، بلا مسار نهائي. عند معاينة موقع في نطاق مختلف، أضف نطاق المعاينة مؤقتًا أو استخدم إعدادًا منفصلًا.
- `ALLOWED_STREAM_HOSTS` اختياري: أسماء المضيفين الإضافية التي يستخدمها مزود البث بعد التحويلات، مفصولة بفواصل؛ أضف المنفذ عند الحاجة مثل `edge.example.com:8080`. لا تضع `*`.

إذا أردت حدًا لمحاولات تسجيل الدخول، أضف Rate Limiting binding باسم `LOGIN_RATE_LIMITER` واجعل المفتاح حسب IP. هذا الربط اختياري في الكود، لكنه موصى به عند نشر Worker عام.

## النشر

انشر Worker ثم ضع عنوانه في إعداد الاتصال بموقع لَمعة. يسجل الموقع الدخول إلى `/auth/login` بكلمة `APP_ACCESS_PASSWORD`، ثم يطلب كتالوج Xtream من `/api/player_api.php` ويستخرج رابط تشغيل مؤقتًا من `/api/stream-url`. روابط `/media` تحتوي تذكرة معتمة مؤقتة لا يمكن فكها إلى بيانات المصدر؛ لا تشاركها علنًا.

## ما الذي تعنيه «دعم الصيغ»

الـWorker يمرّر بايتات المصدر كما هي ويمرّر طلبات Range اللازمة للتقديم والترجيع. يعيد كتابة عناوين قوائم HLS لتُحمّل عبره، بما فيها قوائم `.m3u8` وقطع `.ts`. لا يقوم بتحويل الفيديو أو الصوت. المتصفح هو الذي يقرر الحاوية والترميز المدعومين؛ لذلك لا يوجد Worker وحده يضمن تشغيل كل ملفات MKV/AVI/WMV على كل الأجهزة. التشغيل الشامل لهذه الملفات يحتاج خدمة تحويل/Transcoding منفصلة تملك حق معالجة المحتوى، وقد تحتاج حوسبة ونقل بيانات مدفوعين. لا تحذف هذا القيد من واجهة المستخدم.
